工具名称
位置变化热力图分析工具 (PVHA)

中文描述
这是一款纯前端的位置变化热力图分析工具，主要用于对比多组数据在同一网格位置上的数值波动情况。工具通过计算每个位置在不同数据组之间的标准差或极差，并以热力图的形式直观展示各位置的稳定性——绿色表示变化小（稳定），红色表示变化大（不稳定）。

主要功能
多组数据对比
支持同时导入多组相同维度的网格数据，自动计算每个位置在多组数据中的变化程度。

多种计算方法

样本标准差（除以 n-1）—— 科学计算常用

总体标准差（除以 n）—— 对应图示中的公式

极差（最大值减最小值）—— 简单直观对比

热力图可视化

绿 → 黄 → 红 渐变色，直观反映变化强度

每个单元格显示具体数值

鼠标悬停可查看精确的标准差

统计信息面板

数据组数

网格尺寸（行 × 列）

平均标准差

最稳定位置（标准差最小）

最不稳定位置（标准差最大）

数据格式要求
每组数据以 #*# points = 开头，后续每行为一组网格行数据，数值之间用逗号分隔。示例：

text
#*# points =
#*#    0.062222, 0.061528, 0.028889, ...
#*#    0.060278, 0.059444, 0.039444, ...
所有数据组的行数和列数必须一致

支持同时粘贴多组数据

使用步骤
在文本框中粘贴符合格式的数据

选择合适的计算方法

点击“生成热力图”

查看热力图和统计结果

适用场景
位置追踪数据的稳定性分析

重复测量实验的变异程度评估

传感器网格数据的波动对比

任何需要在同一空间网格上比较多组数值波动的场景

技术特点
纯 HTML/CSS/JS 实现，无需后端服务

数据完全在本地处理，不会上传

响应式界面，支持不同屏幕尺寸

内置示例数据，方便快速体验
